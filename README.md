# Tech Interview Trainer

Приложение для подготовки к техническим интервью в формате карточек и викторины.

---

## Идея проекта

Приложение позволяет:

- Просматривать вопросы по категориям
- Фильтровать и искать вопросы
- Отмечать прогресс изучения
- Проходить режим викторины (quiz)
- Отслеживать статистику
- Добавлять собственные вопросы
- Работать в разных режимах (обучение / игра)

---

## Стек

- React
- React Router
- CSS / CSS modules / Tailwind

---

## Планируемый функционал

### Работа с вопросами
- Просмотр списка вопросов по категориям
- Фильтрация по категориям
- Поиск по тексту вопроса
- Карточка с переворотом (вопрос скрыт до клика)
- Индикатор сложности (лёгкий / средний / сложный)
- Случайный вопрос

### Прогресс и статистика
- Отметка «Знаю / не знаю»
- Избранные вопросы
- Общая статистика
- Статистика по категориям
- График прогресса за неделю / месяц
- Календарь / трекер целей

### Режимы работы
- Режим викторины (несколько вариантов ответа)
- Подсчёт правильных ответов
- Таймер обратного отсчёта
- Сопоставление терминов (drag & drop)
- Таблица лидеров (локальная)
- Возможный мультиплеер (WebSocket)

### Дополнительные возможности
- Добавление своих вопросов (с валидацией)
- Сохранение данных в localStorage
- Темизация (светлая / тёмная тема)
- Локализация (поддержка нескольких языков)
- Голосовой ассистент (озвучивание вопросов)
