# Дата: 29.03.2026

Сегодня почти вся работа была сосредоточена вокруг Квиз. Решил доделать режим чтобы была полноценная игровая викторина.

Так как моя локализация была не полной - только приложение, вопросы были на Русском, решил начать с перевода всех вопросов, чтобы в последующем добавлять уже на двух языках. 
В процесе возникает вопрос - как реализовать добавление вопроса на двух языках в соответсвующем разделе или оставить так как есть. Перевёл все вопросы на английский и добавил новые. 
Добавил типы и прокинул текущую локаль из i18n, чтобы вопросы автоматически подстраивались под язык. Заодно почистил набор - сначала урезал до 60, потом решил вернуть всё обратно - в итоге сейчас 64 вопроса. 

Дальше занялся квизом. Раньше он сразу стартовал с таймером. Сделал нормальный стартовый экран с кнопкой "Начать". После рестарта тоже возвращаемся туда, а не сразу вопросы.

Добавил кнопку "Начать заново" - можно в любой момент сбросить и получить новый набор вопросов. Это кажется мне удобнее, чем только пройти ещё раз в конце.

Добавил звуки. Без файлов, через Web Audio API.
Сделал: звук старта, звук правильного ответа и звук ошибки / таймаута.

Отдельно пришлось повозиться с тем, чтобы в React Strict Mode звуки не дублировались - сделал дедупликацию через ключи сессии. Плюс добавил “сессию квиза”, которая обновляется при старте/рестарте.

Сделал глобальный контекст для звука и кнопку mute в хедере только на странице квиза. Состояние сохраняется в локал сторэдж.

## Что было сделано:

- Локализация для всех вопросов
- Добавлены новые вопросы (общее количество 64)
- Кнопка Начать для квиза
- Кнопка Начать заново во время квиза
- Звуковые эффекты (Web Audio API)
- Звук: старт / правильный / ошибка / таймаут
- Контекст для управления звуком + localStorage
- Кнопка mute в хедере для Квиз
- Дедупликация звуков

## Проблемы:
- Трудности с поиском вопросов
- Дублирование звуков из-за React Strict Mode
- Нужно было разрулить когда именно играть звук (не триггерить лишний раз)
- Автостарт квиза портил UX
- Работа с i18n в данных усложнила типизацию
- Путаница с состояниями (start / restart / session)

## Решения:
- Сгенерировал вопросы + перевод с помощью нейросети
- Ввёл систему ключей и сессий для звуков (dedup)
- Разделил логику: старт - отдельный action, ответы - через effect
- Добавил явное состояние quizStarted
- Привёл типы вопросов к единой структуре
- Вынес звук в отдельные модули и контекст
