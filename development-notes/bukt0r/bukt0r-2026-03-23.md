# Дата: 23.03.2026

Сегодня работая над приложением решил отказаться от сервера - не знаю временно или нет. У меня есть опасения, что я вообще не успеваю и мне сложно продолжать работу занимаясь и сервером в том числе. В любом случае решение было принято,  тем более все необходимые данные уже есть в mock-файле `src/data/questions.ts`.

Я провёл анализ проекта с помощью gpt, чтобы вообще понять масштабы необходимых изменений. Выяснилось, что часть компонентов, например, `QuestionCard` и `DifficultyBadge` работали со старой моделью данных из `features/questions`. В новой архитектуре используется модель из `entities/question/model/types.ts`, поэтому потребовалось привести компоненты к единому формату.

Сначала обновил компонент `DifficultyBadge`, переключив его на использование нового типа `Difficulty`. Логика компонента уже соответствовала требованиям, изменения касались только типизации.

Далее переработал `QuestionCard`: он был переведён на новую модель данных и теперь отображает текст вопроса (`question.question`), категорию (`category`) и уровень сложности через `DifficultyBadge`. Старые поля тайтл и топик айди были удалены.

После этого обновил страницу `QuestionsPage`. Ранее она работала через асинхронный API (`fetchQuestions`), но теперь используется локальный метод `getQuestions()`. Убрал лишнюю логику (loading, error, useEffect), так как данные синхронные. Добавил отображение общего количества вопросов и обработку пустого списка.

Реализовал flip-логику карточки. При клике на карточку теперь показывается ответ, при повторном клике снова вопрос. Добавил поддержку клавиатуры, а также визуальные подсказки для пользователя.

В процессе работы возникали моменты, где было сложно самостоятельно найти причину проблемы особенно при рефакторинге типов и переключении моделей данных. В таких случаях использовал нейросеть для помощи в анализе и поиске решения, что позволило быстрее разобраться и не застревать на одном месте.
