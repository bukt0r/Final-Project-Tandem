На звонке с командой мы обсуждали нужен ли нам серевер или мы будем исаользовать mock-данные и обойдемся без бэка. 
Далее я занялся настройкой проекта. У меня как в учебнике по JS - исторически так сложилось. Так вот исторически 
так сложилось, что у меня всегда сложности с самой базовой вещью - с первоначальной настройкой, и это моя самая
не любимая часть. Я запускал команду npm create vite@latest app -- --template react-ts, команда должна была:
скачать шаблон Vite; создать папку app/; установить зависимости; создать package-lock.json. Но npm упал с 
ошибкой: npm error code EPERM. Вместо изменения системных прав через sudo было принято решение временно переключить 
npm-кэш на локальную папку внутри репозитория (.npm-cache/). Сейчас проект настроен на Vite + React + TypeScript, 
всё находится внутри директории app/. TypeScript переведён в строгий режим. Сборка (npm run build) проходит без ошибок.

## Проблемы:
- Ошибка прав доступа
- Настройка ESLint заняла больше времени, чем ожидалось.
- Были сложности с корректной интеграцией Tailwind через PostCSS.

## Решения:
- По каждой проблеме разбирался через документацию
- Старался не ослаблять правила ради удобства — цель именно строгая архитектурная база.
- Проверял всё через npm run build, npm run lint, npm run format до полного "зелёного" состояния.
