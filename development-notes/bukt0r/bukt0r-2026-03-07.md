# Дата: 07.03.2026
Вчера я занимался реализацией роутинга. Перед началом работы нужно было продумать структуру так, чтобы добавление новых страниц
в будущем не требовало изменений в нескольких местах проекта. Поэтому было принято решение вынести маршрутизацию в 
отдельный модуль. Для этого была создана директория routing, в которой находятся файлы, отвечающие за конфигурацию маршрутов. 
В файле routePaths.ts были описаны все пути приложения в виде констант. Это позволяет не использовать строки напрямую 
в навигации и роутере и поддерживать типобезопасность через тип RoutePath. Основная конфигурация маршрутов реализована
в router.tsx с использованием createBrowserRouter. Корневой маршрут использует компонент Layout, который выступает общей
оболочкой приложения. Внутри него находятся дочерние маршруты для страниц. Страницы подключаются через React.lazy, 
что позволяет автоматически разделить код на отдельные чанки и загружать страницу только в момент перехода на соответствующий
маршрут. Также я отдельно проверил типизацию в router.tsx. Вместо использования глобального React были подключены 
необходимые типы напрямую из библиотеки react, такие как ComponentType и LazyExoticComponent. Это позволило сохранить 
строгую типизацию без использования any. Для страниц была создана директория pages. На текущем этапе они реализованы
как заглушки с явной типизацией FC: HomePage, QuestionsPage, QuizPage, StatisticsPage и FavoritesPage. 
Внутри папки также добавлен index.ts для реэкспорта страниц. После я начал подготовку к записи видео презентации. Тут
уже не было сложностей так как уже не в первый раз.

## Проблемы:
- Потребовалось дополнительно проверить типизацию функции для загрузки страниц, чтобы не использовать глобальный React.
- Нужно было аккуратно организовать структуру файлов, чтобы роутинг не зависел напрямую от страниц.

## Решения:
- Типы ComponentType и LazyExoticComponent были импортированы напрямую из react.
- Создана вспомогательная функция lazyPage для типизированного вызова lazy.
- Все пути вынесены в отдельный файл routePaths.ts, чтобы избежать хардкода строк.
